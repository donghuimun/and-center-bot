# 2026-05-27 작업 로그

## 주요 변경사항

### 1. Vercel 크론 스케줄 등록
- `vercel.json`이 `{}` 빈 파일이라 크론이 아예 등록되지 않은 상태였음
- KST 기준 5개 슬롯 등록: 08:10 / 10:25 / 12:40 / 15:00 / 17:10

### 2. 한국어 + 영어 피드 동시 수집
- 기존: DailyNK 한국어 피드(`/feed`)만 파싱
- 변경: 영어 피드(`/english/feed`)도 동시 파싱
- 각 article에 `lang: "ko"` / `lang: "en"` 필드 추가
- 한쪽 피드 실패 시 나머지로 계속 동작

### 3. RSS content HTML 태그 제거
- 영어 피드 content에 `<p>`, `<a href>` 등 HTML이 그대로 포함되어 있었음
- `_strip_html()` 함수 추가해 플레인 텍스트로 변환 후 Claude에 전달

### 4. 280자 제한 완전 제거
- 프론트(`app/approve/[id]/page.tsx`): `MAX_CHARS` 상수, 빨간 경고, 버튼 비활성화 제거
- 백엔드(`api/approve.py`): 서버사이드 글자 수 검증 제거
- 글자 수는 참고용으로만 표시 (`{count}자`)

### 5. 중복 트윗 방지 (atomic 상태 전이)
- 기존: `pending` 확인 → X 포스팅 → DB 업데이트 (순서 문제 + race condition)
- 변경: `pending → posting` 원자적 전이 후 포스팅 → `posted` 업데이트
- 동시 요청이 들어와도 한 요청만 `posting` 전이에 성공
- Supabase migration `004_add_posting_status.sql` 실행 필요

### 6. Rate limit 재시도 가능
- 기존: 429 rate limit 포함 모든 실패가 `failed`로 고정 → UI에서 재시도 불가
- 변경: 429 시 `pending`으로 복구해 재시도 가능하게 처리

### 7. Claude 응답 품질 개선
- `generate_draft`에 `title` 파라미터 추가 (프롬프트 구조화)
- `_extract_text()`: content block 방어적 파싱
- `_validate_draft(text, url)`: 한글 포함 / URL 누락 / 해시태그 3개 미만 시 재시도
- `max_tokens` 1500 → 800

### 8. 훅 전략 정비
- HOOK FORMULA: 10개 → 4개 (Scene / Shock Number / Direct Quote / Contradiction)
- HOOK SELECTION RULE 추가: 기사 내용 기반 우선순위 명시
- Question, Before vs Now, Provocative Claim 등 제거
- GOOD EXAMPLES도 4개 훅 정책에 맞게 교체
