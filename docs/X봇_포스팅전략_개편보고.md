## 한 줄 요약

**"기사를 감성적 장면으로 각색하는 봇" → "기사 속 사건의 책임 구조를 분석하는 봇"** 으로 전환했습니다.
단순 요약이나 분노 표출이 아니라, *누가 결정했고 누가 비용을 치르는가*를 짚는 짧은 국제정치 분석 코멘터리를 지향합니다.

---

## 기존 vs 개편 비교

| 구분 | 기존 (장면 스토리텔링) | 개편 (책임 구조 분석) |
|---|---|---|
| **포스트 성격** | 기사를 감성적 장면으로 재구성 | 사건 뒤의 정치적 선택을 분석 |
| **핵심 질문** | "어떤 장면이 체제를 보여주는가" | "누가 결정했고, 누가 이득을 보고, 누가 비용을 치르는가" |
| **글 구조** | 감성 훅 → 맥락 → 차가운 마무리 | 분석적 판단 → 기사 속 근거 → 책임 소재 → 판결형 마무리 (사건 서술로 시작 금지) |
| **분석 프레임** | 숨겨진 프레임 (명시 금지) | 6개 국제정치 렌즈 중 택1 (체제 생존, 제재 정치경제, 북중러 진영, 억지 시그널링, 정보 통제, 국가 vs 시장) |
| **비판 대상** | 사실상 북한 정권 단일 | 5개 타겟으로 확대: 정권의 결정, 제재 설계의 맹점, 중·러 조력, 국제사회 무관심, 한미 정책 공백 |
| **1순위 독자** | 일반 대중 60% | 저널리스트·애널리스트 50% |
| **인게이지먼트 전략** | 감정적 여운 (충격, 아이러니) | 인용트윗 유발 (동의/반박 가능한 정밀한 주장) |

---

## 왜 바꾸는가

1. **인용 가치**: 감성 스토리텔링은 스크롤을 멈추게 하지만, 저널리스트가 기사에 인용하는 것은 "요약"이 아니라 "주장"입니다. 계정 성장이 리플라이·인용 등 네트워크 이벤트에서 나온다는 운영 데이터와도 부합합니다.
2. **차별화**: 단순 요약 봇은 대체 가능하지만, 일관된 분석 프레임을 가진 계정은 팔로우할 이유가 됩니다.
3. **포지셔닝**: 북한만 비판하면 "반북 계정"으로 읽히지만, 제재 설계·중러 조력·정책 공백까지 같은 잣대로 감사(audit)하면 **국제정치 분석 기관**으로 읽힙니다. 싱크탱크 브랜드에 부합합니다.

## 리스크와 안전장치

| 리스크 | 안전장치 (프롬프트에 명문화) |
|---|---|
| 과도한 책임 귀속 (기사 근거 부족한 단정) | 기사가 책임자를 명확히 지목할 때만 특정 행위자 비판. 불명확하면 유인구조·거버넌스 패턴 비판으로 후퇴 |
| 활동가 계정처럼 보일 위험 | 도덕적 수사(brutal, cruel 등) 금지. 분노가 아니라 "누가 선택하고 누가 지불하는가"의 장부가 곧 비판 |
| 근거 없는 주장 | 모든 비판적 주장은 반드시 기사 안의 팩트에 앵커. 외부 사건·수치 반입 금지 |
| X 글자수 초과 | 기존 자동 검증(본문 220자, 전체 280자) 유지 + 초과 시 자기수정 재시도 루프 그대로 |

## 변경하지 않은 것

- 발행 파이프라인 (RSS 수집 → 생성 → 검증 → 발행)
- 품질 검증 규칙 및 실패 시 자동 재시도 (최대 4회)
- 해시태그·링크·UTM 추적 정책
- API 비용 구조 (호출 횟수 동일)

## 톤 비교 예시

**기존:**
> A provincial official spent another day running on foot. No materials arrived. No funding arrived. ... The slogan stayed in Pyongyang. The fear did not.

**개편 (판단 → 근거 → 판결 순서):**
> **North Korea's containment failure is an allocation choice, not a resource problem.** The order came with no feed, no funds — and pig farming collapsed to a third of households. **Control stays central. Losses are socialized.**

**개편 (정권 외 타겟 — 제재 설계 비판):**
> **North Korea's labor exports are not a violation story. They are a design story.** While "training" visas stay open, about 100 workers cross into China daily — legally, on paper. **The loophole wasn't discovered. It was left there.**
